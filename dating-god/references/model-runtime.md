# 模型自由互动

本地网页使用本地Node服务调用模型。离线网页继续支持原有分支，不需要模型；两种入口明确区分。模型模式包含自由输入、场景动作、四档氛围、暂停、取消、重演及原有HTML回看和SVG卡片。

## 启动

需要Node.js18或更高版本，无需安装第三方依赖。在Skill目录运行：

```powershell
node scripts/live-server.cjs
```

按终端显示的本地HTTP地址打开页面。未配置模型时可以检查页面或使用离线体验；选择模型互动时会明确提示配置问题。

模型配置使用服务进程环境变量。在同一PowerShell窗口设置后启动（将占位符替换为自己账户可用的配置）：

```powershell
$env:OPENAI_API_KEY = "你的API密钥"
$env:OPENAI_MODEL = "支持Chat Completions与json_schema的模型ID"
node scripts/live-server.cjs
```

默认访问`http://127.0.0.1:3781`。端口被占用时先设置`$env:DATING_PORT = "3782"`。只监听本机，不作为公网或手机局域网服务。环境变量修改后需要重新启动服务；按Ctrl+C停止，内存会话随进程结束消失。

当前通道固定为OpenAI官方`https://api.openai.com/v1/chat/completions`，要求模型支持严格JSON Schema输出。不提供任意base_url或自动读取桌面登录的功能。密钥不填入网页、不写入公开仓库。模型调用可能产生费用，对话会发送到该服务；无配置时启动不会调用模型。协议和故障路径已通过本地模拟服务测试，真实账户授权、模型表现和计费仍需使用者配置后验证。

## 互动与状态

用户输入与动作提交到本地服务；服务保存权威会话，浏览器不上传自己伪造的角色历史。模型生成自然台词与可见动作，引擎负责有效动作、时间、暂停退出及已确认的约定。服务端事件以source字段区分model与engine来源，界面不额外展示这些技术字段。

角色表达底稿、四档氛围与原创互动例子位于`assets/dialogue-data.js`。例子是写法参考，不能作为本场记忆。用户的私人便笺和个人期待不默认作为角色已知信息发送。

收到完整回应并校验后再提交本轮。当前采用整轮JSON回应，不承诺逐字流式。失败保留当前进度；重试、取消或暂停不能让过期回应写入后续回合。用户在输入框前的真实等待不推进剧情时间。

本轮仍使用3场景、8角色。24活动、32角色属于后续内容扩充，不能在产品介绍中当成已发布能力。ChatGPT授权桥接、本地模型与训练模型尚未接入。
