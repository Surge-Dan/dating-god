# Dating之神 · Dating God

## 启动一场

1. 用户明确要启动时，定位本 Skill 的 [约会首页](assets/index.html)，用可用的宿主导航能力打开本地网页。只有确认已经打开时才说「已打开」。桌面 Windows 如果没有专用导航工具，且本机能打开用户请求的网页，用 PowerShell 的 `Invoke-Item -LiteralPath` 打开该文件。只执行固定入口，不拼接用户输入。
2. 同一条回复提供指向该文件的可点击入口。宿主明确拒绝导航或缺少导航能力时，直接给入口，说明需要在能访问 Skill 目录的浏览器里手动打开。只确认用法或想了解功能时，先回答问题。
3. 让网页处理成年确认、地点、对象偏好、边界、约会和回看。保持完整Skill目录。直接打开文件进入离线体验，无需API或联网；模型自由互动需要先按[模型运行说明](references/model-runtime.md)启动本地服务，从HTTP入口打开。只在用户选择模型互动且通道已经配置时发送模型请求，不自行查找凭据或承诺免费。
4. 包含24个活动、32位原创成年角色。活动与关系起点分别选择，支持初见、第二次见面、朋友、暧昧和稳定交往。动作按前置条件改变进度与物件，第二站需要双方确认。页面里的提示、暂停、降档和重演都属于当前这一场。
5. 模型模式同时接受自由输入和动作选项。四档体验影响角色表达与张力，角色仍受现场事实、时间和边界约束。男生视角匹配女性角色，女生视角匹配男性角色；其他视角按用户对象偏好匹配。模型超时不能声称角色已回应或约定已成立。

## 完成与退出

- 成年确认由页面完成。已明确未成年时不启动成人模拟。遇到用户正在经历现实危险、胁迫或即时伤害风险时，先按宿主的安全流程回应现实情况。
- 用户在网页里自由决定是否看回看、核对后下载HTML或下载确认过的Dating卡。回看可能包含现场原话，不承诺自动识别全部个人信息。向用户解释报告时，只使用用户主动提供的文件或材料，按[回看与分享规则](references/review.md)区分现场记录、虚构角色、解释和本人确认。
- 每次启动都是独立场景，不把上次故事、身份或约定带入角色记忆。自查记录默认仅本场；用户可选择保留在本机，不要求注册或填写现实人物资料。用户明确取消就停止启动或说明可关闭页面。

## 现场避雷与自查

- 下头避雷器根据已提交言行与实际前情提醒。区分明确边界、互动摩擦、偏好协商和照顾机会；AA、低预算、紧张、平等表达、受邀讲解、正常暂停和安全退出不自动判错。
- 普通提醒附在回合旁，不替用户道歉、不强制角色原谅。引用、假设、未发送草稿和描述他人行为不能归责用户；未执行的动作不能记成已发生。
- 首页支持查看自查记录、提出异议和微练习。原局、重演、练习及用户补记来源分开；模拟行为不等于现实人格，角色自己的冒犯不计入用户负面历史。
- 独立语义评估会额外调用当前配置的模型；失败、额度不足或离线只能按实际覆盖说明，不承诺完整识别。未发送草稿只在主动预检时发送。
- 本机保存、清空与分享规则见[避雷器使用说明](references/radar.md)。报告和Dating卡不自动带入自查簿。

## 维护与排查

- 修改匹配、状态、场景或重演时，先读 [约会引擎约定](references/engine.md)。内容源在 `assets/content.js`，验证前不要把草稿角色或场景加进匹配清单。
- 修改复盘证据、隐私和文件交付时，先读 [回看与分享规则](references/review.md)。网页代码无法可靠地识别自填文字里所有真实身份信息，确认与预览是用户控制分享范围的入口。
