# 回看与分享

- 先回放已发生的动作、回应和结果，再请用户选择一个在意的时刻。玩家点击动作时按「你选择了」呈现，角色引用逐字来自实际回合。原场、重演和未确认的解释分开。
- 候选感受只当草稿。只有本人主动确认的句子能以第一人称写入发现和分享卡。可以跳过，保留观察和自问句。交付建议用一个低成本动作和一个可以看到的观察信号，单场行为不用于判定人格或推测真人动机。
- HTML 默认排除称呼、角色名、赴约期待和用户私人便笺。用户可分别勾选附上自己的期待与便笺，写入前在回看页面预览。只回看或提前退出不会自动写文件。
- 4:5 SVG Dating 卡只用用户认领且预览过的一句话和可选观察点。过滤常见联系方式以及当前角色名和称呼，避免逐字回放剧情。建议使用通用表述，用户手填的文字仍由本人核对。
- 页面与 HTML 导出无需联网。没有可引用互动时只给反思问题或用户自己确认的发现。重置不会删除用户已经下载的文件。
