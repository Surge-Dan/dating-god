给当代恋爱练习生准备的赛博约会Skill。咖啡馆初见、朋友突然单独约饭、第二次约会一起捏歪杯子，有人接梗，有人慢热，有人聊得正开心却掐点赶车。

你可以挑个人、选个地方，再决定等位还是出门、接话还是留白、再约还是散场。对方也有自己的安排，会提出备选、明确拒绝，或者到点离开。散场后领一份约会回看和个人Dating卡，看看这次到底是心动了，还是终于敢说「我想坐里面」。

包含3个场景、8位原创成年角色、15个角色与场景组合。每次启动都是一场独立体验，选择、重演和回看都在这一场完成。

## 📦安装与使用

把下面这段话发送给支持本地Skill的助手。

```text
请从以下仓库安装dating-god。
https://github.com/Surge-Dan/dating-god
保留完整的Skill目录及其中的assets、agents和references。
```

安装后，在新聊天里说。

```text
使用$dating-god，开始一场约会。
```

助手会尝试打开约会网页，并提供本地入口。支持网页导航的桌面宿主可直接打开，其他环境需要在能访问Skill文件的浏览器里手动打开。

想先试玩，可以下载整个仓库，在浏览器中打开`dating-god/assets/index.html`。保持页面与配套文件的目录结构，即可进入，无需安装依赖或配置APIKey。

## 🪄从开场到散场，怎么玩

|环节|你做什么|会发生什么|
|---|---|---|
|<strong>①选个开局</strong>|确认已年满18岁，直接盲约或继续细选|盲约从书店咖啡首见开始，细选可以调整对象和相处偏好|
|<strong>②写下期待</strong>|选地点，写一句「这场约会，我希望……」，标记避开的话题|期待留给自己，角色只知道你们现场实际表达过的事|
|<strong>③看见面便笺</strong>|看看对方的爱好和互动风格，决定赴约或换一位|从当前条件允许的角色中匹配，先认识一点，再到现场慢慢了解|
|<strong>④按自己的节奏玩</strong>|选择眼前的动作，可以接话、换地点、留白、邀约或道别|地点、可选动作、剧情时间和双方约定随选择变化|
|<strong>⑤选一刻回看</strong>|散场后选一个在意的片段，写下感受，也可以跳过|先回放动作、原话和结果，再邀请你确认这一刻意味着什么|
|<strong>⑥带走或重来</strong>|在本场重演一个节点，或预览后下载回看与卡片|原场和重演分别记录，本次结束后可以重新开启一场|

### 🎛️赴约前能选什么

- <strong>对象与视角。</strong>可选女性、男性、非二元对象，也可以选「都可以」或「暂不指定」。后者在候选便笺中先隐藏性别。玩家视角和称呼都可留空。
- <strong>相处偏好。</strong>最多选3项，例如有主见、给彼此空间、愿意回问、会接梗、说到做到、慢慢熟悉。先选的优先，再结合兴趣匹配。
- <strong>话题边界。</strong>可以避开前任、亲密话题、外貌评价、拍照、工作和定义关系，相关动作会从本场选项中移除。
- <strong>现场节奏。</strong>可以允许一点场景小变化，也可以在开场时要一个行动方向。候选不足时会显示实际结果，再由你调整设置。

## ☕今天约在哪里

|场景|开场|你可能遇到的选择|
|---|---|---|
|<strong>书店咖啡首见</strong>|窗边满座，对方拿着两张等位号|等位还是散步，选安静座位还是聊聊旧书|
|<strong>朋友第一次单独见面</strong>|平时一群人拼桌，今晚只有两副碗筷|先点菜、谈谈这次见面的含义，或保持原来的节奏|
|<strong>第二次约会做陶艺</strong>|面前有两只还没成形的杯子|救一下歪杯沿、留着它，或商量下次上釉|

同一条邀请可能被接受、追问、暂缓或拒绝。对方提出时间地点后，还要等你确认才算约好。拒绝、保留意见和愉快告别都能走到完整结局。

## 🎭8位有自己生活的角色

|人物|相处时的样子|约会之外还有什么事|
|---|---|---|
|<strong>林澈</strong>|有自己的选项，也能一起安静待着|要去取修好的相机|
|<strong>任榆</strong>|愿意回问，会从手上的小事里接梗|要给朋友送回布展工具|
|<strong>邱岩</strong>|先听完，再给一个具体安排|还要赶社区球赛的集合|
|<strong>顾宁</strong>|留意细节，给沉默留一点空间|要搭车回去，通勤比较长|
|<strong>夏译</strong>|愿意让话题缓一缓，想清楚再接回去|背着谱子来，之后还得回排练场|
|<strong>陈诺</strong>|手上有活时更好开口，也能笑看歪杯子|要把借来的工具还回去|
|<strong>闻嘉</strong>|能接住自嘲，遇到冷场会捡个小梗|答应帮朋友收市集|
|<strong>陶桥</strong>|记得熟人的偏好，含糊的安排会先问清楚|晚些要到站口接朋友|

角色按对象条件、场景和偏好组合，并保留自己的时间与表达方式。例如，同样问「能不能再待一会儿」，有人会拒绝延长，有人会提出一起走5分钟，也有人选择在这里散场。

## 🧭选择怎样改变这一场

- <strong>换地点会换后续。</strong>等位后可以看旧书、挑座位；选择出门，后续就发生在巷子里。
- <strong>提议和约定分开。</strong>「周六见吗」先是一方的提议，你确认后才成为双方约定。
- <strong>边界会留在剧情里。</strong>对方拒绝延长后，同类动作随之关闭；角色提出的其他安排，需要你另行选择。
- <strong>时间只跟着剧情走。</strong>有效动作会消耗本场时间，浏览器前的等待、提示和暂停都不会。到离场时间，角色按自己的安排道别。
- <strong>顺利和分开都能收场。</strong>可以约好再见，可以还没谈拢，也可以觉得今晚已经足够。

### ⏸️卡住、暂停或想重来

|页面操作|用途|
|---|---|
|<strong>我有点卡住</strong>|给当前可见的行动方向，帮助你找到下一步|
|<strong>暂停／回到现场</strong>|先歇一会儿，回来从同一刻接上|
|<strong>提前散场</strong>|随时结束本场，再选择是否回看|
|<strong>从这一幕重演</strong>|散场后选一个回合，从它发生前试一次其他做法|
|<strong>结束并清空这场</strong>|回到封面，下次按新场次开始|

每场可以重演一个节点。重演沿用同一个角色、前情和已经说清的边界，原场记录保留在回看里，两种走法可以对照。

## 🎟️散场之后能带走什么

|产物|包含什么|适合怎么用|
|---|---|---|
|<strong>HTML约会回看</strong>|现场动作、角色原话、剧情结果、选中的一刻，以及实际完成的重演|留给自己慢慢读，回想当时怎样表达、对方怎样回应|
|<strong>个人Dating卡</strong>|一张4:5的SVG便笺，放一句你确认过的发现和可选观察点|保存或分享这一场想带走的东西|

回看按「发生了什么→我当时在意什么→我想带走什么」展开。可以用一个候选发现作草稿，再改成自己的话。认领后，这句话才会进入个人发现和分享卡。

想写就写，想跳过也可以。跳过自述和确认时，回看保留现场和待观察的问题。一个动作只描述这一场的选择，能否再约也只是本场结果。

赴约期待和私人便笺分别勾选后才加入HTML。卡片下载前会显示预览，是否附上下次观察点由你决定。文件在点击下载时生成，单次体验就可以完整结束。

## 🔐数据与使用说明

- <strong>成年人场景。</strong>面向18岁以上用户，所有约会角色均为原创虚构人物。
- <strong>本地运行。</strong>网页运行期间无需请求模型或外部接口。
- <strong>单场独立。</strong>每次启动、重置和重载都新开一场。关闭页面后本场状态结束，已下载文件由你保存。
- <strong>自主分享。</strong>称呼、联系方式和角色名默认排除在导出之外，自己编辑的便笺和发现仍需在分享前核对。
