一款给当代恋爱练习生准备的赛博约会 Skill。咖啡馆初见、朋友突然单独约饭、第二次约会一起捏歪杯子，有人接梗，有人慢热，有人聊得正开心却掐点赶车。

你可以挑个人、选个地方，再决定等位还是出门、接话还是留白、再约还是散场。角色也有自己的安排，会提出备选、明确拒绝，或者到点离开。散场后领一份约会回看和个人 Dating 卡，看看这次到底是心动了，还是终于敢说「我想坐里面」。

**当前是本地试映版。** 网页通过预写动作和对白分支推进，包含三个场景、八位原创成年角色。每次启动是一场独立体验，关系里的选择、重演和回看都在这一场完成。

## 安装与使用

将下面这段话发送给支持本地 Skill 的助手。

```text
请安装 https://github.com/Surge-Dan/dating-god 中的 dating-simulator Skill。
安装完整的 dating-simulator 目录，保留 assets、agents 和 references。
```

安装后，在新聊天里说。

```text
使用 $dating-simulator，开始一场约会。
```

助手会尝试打开约会网页，并提供本地入口。支持网页导航的桌面宿主可直接打开，其他环境需要在能访问 Skill 文件的浏览器里手动打开。

想先试玩，也可以下载整个仓库，在浏览器中打开 `dating-simulator/assets/index.html`。页面与配套文件需要放在同一目录结构下，无需安装依赖或配置 API Key。

## 第一次赴约

1. **选一个开局。** 确认已年满 18 岁后可以直接盲约，也可以选择对象呈现、玩家视角、相处偏好和兴趣。
2. **挑地点、定边界。** 写一句本场期待，选想避开的话题。期待留给自己，角色只知道现场实际表达过的事。
3. **看看见面便笺。** 从爱好和互动风格认识对方，想换人就换一位。
4. **按自己的节奏玩。** 选择动作推进，卡住可以要提示，随时暂停或提前散场。
5. **散场后再看看。** 选一刻回放，说说自己在意什么，也可以跳过。需要时重演一个节点，再决定是否下载。

## 散场之后能带走什么

| 产物 | 内容 |
| --- | --- |
| **HTML 约会回看** | 现场动作、角色原话、实际结果和选中的一刻。完成重演时，原场和重演分开展示 |
| **个人 Dating 卡** | 一张 4:5 SVG 便笺，只放你确认过的发现和可选的下次观察点 |

回看先还原发生了什么，再邀请你确认感受。候选发现可以自己改写，也可以跳过。认领一句话之后才生成分享卡，单次行为只用于描述这一场。

期待和私人便笺分别勾选后才加入 HTML。分享卡下载前可以预览，是否加入下次观察点由你决定。

## 数据与使用说明

- 面向成年人，所有约会角色均为原创虚构人物。
- 网页在本地运行，运行期间无需请求模型或外部接口。
- 每次启动、重置和重载都新开一场。关闭页面后本场状态结束，已下载的文件由你保存。
- 称呼、联系方式和角色名默认排除在导出之外。自己编辑的便笺和发现仍需在分享前核对。
- 当前自由对白、在线服务与更多场景属于后续接入阶段。现实中的关系问题由宿主按普通咨询流程处理。

```text

│   ├── index.html            # 网页入口

tests/                        # 状态、导出与页面事件测试
```

## 开发与验证

在仓库根目录使用 Node.js 18 或更高版本运行。

```powershell
node --test tests/dating-simulator.test.cjs tests/dating-page.test.cjs
```

当前通过 17 条自动测试。独立对抗审查覆盖了 120 组配置、18,348 条结束路径和 102,260 个重演快照，修复了角色说要离场但状态未结束、拒绝后仍能推进和回看内容不一致等问题。

实际浏览器渲染、窄屏布局、原生下载和安装后的自动打开仍待实测。页面事件测试在 Node 环境执行，完整范围见[对抗审查记录](dating-simulator-对抗审查.md)。
