嘴上说“我都行”，真到点菜时又有点想法。想多待一会儿，对方却还得赶车。刚说完一句土味情话，对面可能接梗，也可能笑你：“好土。”

Dating之神把这些小场面放进一次虚构成年约会。临近赴约，可以带上已有安排，挑人、选地点，再练最在意的一段。只想练一句，也可以直接从开场、接话、表达不同意见、道别或邀请下次见面开始。

## 🧩先准备这一场，再去见面

从首页点「准备这次见面」。在「本场准备」里写练习目标和已确认的安排。换对象或场景时，可以先浏览和筛选，再明确应用。返回准备页后，刚填的内容和其余已选条件会保留。

- <strong>对象自定义：</strong>外貌、相处方式、生活选择、本次条件分开设置，未知可以留空。随机生成可锁住部分条件。
- <strong>行为随条件变化：</strong>对象模型结合话题、剩余安排与已发生互动选择回应策略；小动作需要物件和活动条件，不每轮重复表演。
- <strong>地点可以自定义：</strong>可沿用已有活动，或选用拼豆、网球、操场模板。费用、营业和预约信息需自行确认。
- <strong>准备结果可带走：</strong>区分人物假设、未知信息和实际预演事件，整理自己认领的下一步做法。

人物标签只用于这场模拟。随机生成遵守已锁定的条件，也受同意、隐私和离场规则约束。[对象与场景说明](dating-god/references/preparation.md)

## 🧯说错以后，还有下一句

网页自由练习中，打开「看看怎么接」可以选一句参考，也可以用「帮我顺一句」整理自己的草稿。填入建议后仍可修改，点「发送」才会提交这一轮。

现场可「暂停」「结束并复盘」或「清空本场」。第二站提议从「提议换个地方…」进入，双方确认后才切换地点并计入预算。移动端选中角色后，点「查看档案」可从底部打开资料并选用该角色。

散场后，复盘把建议和发生过的原话放在一起。只聊一句也可以查看原话并从同一时刻再试。主动保存后可在「复盘」查看或删除摘要。导出HTML默认只带摘要，完整对话和私人便笺可分别勾选。分享卡单独预览和确认。

有旧版笔记时，可在「复盘」页打开「管理旧笔记」。[避雷器说明](dating-god/references/radar.md)

## 🚀快速开始

### 方式一：安装为Skill

把下面这段话发给支持本地Skill的助手：

```text
请从https://github.com/Surge-Dan/dating-god安装dating-god。
保留dating-god目录中的全部文件，包括assets、scripts、agents和references。
```

安装后，在新聊天里说：

```text
使用$dating-god，开始一场约会。
```

Skill默认从网页首页开始。如果想在Agent聊天里练习，可以直接对助手说「在聊天里预演」。[宿主运行协议](dating-god/references/host-runtime.md)

### 方式二：直接打开网页

|入口|怎么启动|互动方式|需要什么|
|---|---|---|---|
|<strong>网页自由聊天</strong>|启动本地服务，打开终端显示的地址|自由输入＋场景动作|Node.js18或更高版本、OpenAI API密钥及支持的模型|
|<strong>离线体验</strong>|打开`dating-god/assets/index.html`|浏览与准备、点选收尾示例|完整下载的文件，无需API或联网|

打开PowerShell，下载仓库并启动服务。已下载仓库时，在仓库根目录从设置环境变量开始。

```powershell
git clone https://github.com/Surge-Dan/dating-god.git
cd dating-god

$env:OPENAI_API_KEY = "你的API密钥"
$env:OPENAI_MODEL = "支持Chat Completions与json_schema的模型ID"

node dating-god/scripts/live-server.cjs
```

将两个占位符换成自己的配置，打开终端显示的地址，默认是`http://127.0.0.1:3781`。启动无需安装第三方依赖，按`Ctrl+C`可停止服务。已有预览可在相同端口运行`node dating-god/scripts/live-server.cjs --verify`，核对协议版本、静态资源和模型配置。

页面显示「自由聊天尚未连接」时，可以打开「查看连接方式」，也可以体验「看收尾演练示例」。示例结束后可返回原来的准备。启动和打开页面本身不会调用模型，首次发送可验证实际生成。网页服务使用OpenAI官方Chat Completions接口，调用费用以服务商规则为准。[网页运行说明](dating-god/references/model-runtime.md)

## 🎚️今天想练什么强度

|模式|这一场的感觉|
|---|---|
|🌱新手尝鲜|有人愿意接话，意图较清楚，适合慢慢进入状态|
|🍬心动试探|轻轻反问、顺手接梗，那半句话可能是在约下次|
|♟️暧昧过招|聊得来，想法却未必一样；需要试探，也需要说清楚|
|🔥地狱修罗场|更多含糊回应、期待落差和取舍，看看自己愿意投入到哪里|

网页赴约预演可在「更多设定」中选择强度和关系类型。短练可调整长度和说话节奏。宿主聊天也支持四档强度。明确拒绝、暂停和退出在每一档都有效。

## 🗺️24个活动，约在哪里由你选

|分类|活动|
|---|---|
|🍜吃喝|咖啡茶饮、餐厅约饭、火锅烤肉、夜市小吃|
|🎬文娱|电影院、美术馆展览、书店|
|🌿户外|公园散步、CityWalk、骑行、野餐短徒步|
|🛍️逛街|市集快闪|
|🏺手作|陶艺、烘焙、饰品绘画|
|🎲游戏|桌游、台球、保龄球、电玩城|
|🏸运动|羽毛球、攀岩|
|🌙夜间|清吧、热闹酒吧、Livehouse|

每个活动有6个核心节点和专属动作。陶艺可以选形状、救杯沿、请店员收好；烘焙需要分工、等待和分装；电影与演出期间少说长话，散场后再聊。

动作会改变物件、进度、位置、时间或模拟消费。保留歪杯子、换一家摊位、承认自己不会，都可以继续。

<strong>想续第二站？先商量。</strong>候选会检查人物兴趣、剩余时间、预算和虚构营业时段；单独确认后才出发，也能撤回。预约、售票和运动活动不会临时自动入场。活动价格、时长和营业时段均为虚构设定，不是现实商户信息。

## 🎭32位角色，各自有自己的生活

人物按兴趣参加不同活动，也有各自适用的体验模式。匹配会考虑对象条件、活动、相处偏好和兴趣；选定模式后，候选范围会进一步缩小。

|人物举例|相处时的样子|之后还有什么安排|
|---|---|---|
|林澈|有自己的选项，说话直接，也能一起安静待着|取修好的相机|
|陈诺|稍紧张，愿意尝试，也会承认自己不会|归还借来的工具|
|许棠|喜欢沿河走路、研究桌游规则，在意意见不同还能否自在相处|照看朋友寄养的猫|
|苏晴|喜欢轻合作游戏，希望输了也能正常聊天|回家处理预约维修|

角色可以主动提议、表达不同意见、没接住玩笑，再试着澄清。共同笑点来自本场真正发生的事，互动例子只教表达方式，不冒充你们的共同记忆。

「更多设定」可调整本场视角及对象偏好。所有角色均为原创虚构成年人。

## 🪄从开场到散场，怎么预演

|环节|网页操作|
|---|---|
|选入口|点「准备这次见面」，或点「挑一个想练的时刻」。短练可以选预设，也可以写一句自己的情况|
|准备与开场|可用推荐对象和场景，也可以换好再应用。赴约预演可在「更多设定」调整时间、预算、关系起点、饮食与边界。确认成年后点「开始预演」或「开始自由练习」|
|现场|在「你想怎么回？」写自己的话，点「发送」。「现场可以做什么」会列出当前可用动作。若出现第二站提议，确认后才切换地点并计入预算|
|暂停或继续|点「暂停」可在同一场继续。点「暂停并离开」后，可用「返回约会现场」回来，再点「继续本场」|
|回看与重演|点「结束并复盘」查看已确认对话。从某句点「从这句再试」，可在同一回合前换个回答，结束后对照两次回应|
|保存与下载|点「保存摘要」存到当前浏览器，或用「导出报告」下载HTML。也可以另做一张SVG分享卡|

### ⏸️发送没成功时

网页按整轮显示回复。未提交的文字保留在输入框，可以修改或点「重试这句」。如果暂时无法判断是否送达，先点「核对发送状态」。点「取消等待」后，已提交的回复会同步显示，尚未提交的文字仍可继续编辑。

## 🎟️散场之后，带走一点什么

|产物|里面有什么|
|---|---|
|<strong>本机复盘摘要</strong>|练习目标、场景和一条本场观察。可在「复盘」按类型或场景筛选、再练或删除|
|<strong>HTML复盘</strong>|默认下载摘要，可分别勾选完整对话和私人便笺。下载前可查看预览|
|<strong>Dating分享卡</strong>|一张4:5的SVG卡片，写一句自己的感受，预览并确认后下载|

已经结束的赴约预演可编辑赴约清单，写下想试的做法、需要向对方确认的问题，以及计划变了时的备选。

## 🔐数据与使用范围

- 面向18岁以上用户。人物、活动价格与行程均属虚构，不代表现实关系诊断。
- Agent聊天遵循宿主的数据规则。网页自由聊天会向模型服务发送生成回复所需的设定和已发送对话，主动点「帮我顺一句」也会发送当前草稿。密钥由本地服务读取。离线示例无需调用模型。
- 宿主临时JSON包含本场原话，退出/交付时由Agent清理，不会在2小时后自动过期；用户保存的配置与报告保留。宿主聊天日志遵循其自身规则。网页API会话在进程内存中，空闲2小时自动清理；停止服务也会释放。
- HTML可能包含现场原话，无法保证自动识别所有个人信息。卡片会过滤部分身份信息与照抄台词，分享前仍需核对。
- 模型可能误解语义。系统校验合法动作与部分严重事实矛盾，但不能保证每一句都自然或完全符合前情。

## 🛠️开发与验证

快速跑引擎和页面回归，在仓库根目录执行：

```powershell
node --test tests/dating-god.test.cjs tests/dating-page.test.cjs
```

完整质量检查使用Node24，包含Node回归与覆盖率、Gherkin、Chromium响应式及无障碍检查，以及报告证据的定向变异测试。浏览器用模拟模型验证自由回复、失败恢复、重演和导出。真实模型表现与真机浏览器仍需单独验证。[质量检查说明](qa/README.md)
