嘴上说“我都行”，真到点菜时又有点想法。想多待一会儿，对方却还得赶车。刚说完一句土味情话，对面可能接梗，也可能笑你：“好土。”

Dating之神把这些小场面放进一次独立的虚构成年约会。你挑活动、选对象，自己说话，也能选择现场动作。人物有自己的兴趣、意见和安排；聊得来可以再约，不合拍也能自然散场。

|现在能玩什么|内容|
|---|---|
|🗺️活动|24个活动，覆盖吃喝、文娱、户外、逛街、手作、游戏、运动和夜间场景|
|🎭人物|32位原创成年角色，16男16女；每个活动至少4男4女可选|
|🧩现场|144个活动节点、295个场景动作、202个角色与活动组合|
|💬互动|模型自由输入＋动作选项，配合48条原创条件式互动例子|
|🎟️散场|回看、单节点重演、HTML约会记录与SVG个人Dating卡|

## 🚀快速开始

### 方式一：安装为Skill

把下面这段话发给支持本地Skill的助手：

```text
请从https://github.com/Surge-Dan/dating-god安装dating-god。
保留dating-god目录中的全部文件，包括assets、scripts、agents和references。
```

安装后，在新聊天里说：

```text
使用$dating-god，开始一场约会。
```

助手会提供或尝试打开本地网页。模型模式还需要完成下面的服务配置；直接打开HTML可使用离线体验。

### 方式二：下载仓库，直接运行

|入口|怎么启动|互动方式|需要什么|
|---|---|---|---|
|**模型自由互动**|启动本地服务，从HTTP地址打开|自由输入＋场景动作，模型根据人物和前情回应|Node.js18+、OpenAIAPI密钥及支持的模型|
|**离线体验**|打开`dating-god/assets/index.html`|预写对白与分支动作|完整下载的文件，无需API或联网|

**模型模式启动步骤**（在仓库根目录的PowerShell窗口执行）：

```powershell
git clone https://github.com/Surge-Dan/dating-god.git
cd dating-god

$env:OPENAI_API_KEY = "你的API密钥"
$env:OPENAI_MODEL = "支持Chat Completions与json_schema的模型ID"

node dating-god/scripts/live-server.cjs
```

将两个占位符换成自己的配置，然后打开终端显示的地址，默认是[http://127.0.0.1:3781](http://127.0.0.1:3781)，选择“模型自由互动”。无需安装第三方依赖，按Ctrl+C停止服务。

当前接入OpenAI官方Chat Completions接口，模型调用可能产生费用，不自动使用ChatGPT订阅额度。启动服务和打开页面本身不会调用模型。端口调整、安装后的目录用法等见[模型运行说明](dating-god/references/model-runtime.md)。

## 🎮今天想玩什么强度

|模式|这一场的感觉|
|---|---|
|🌱新手尝鲜|有人愿意接话，意图较清楚，适合慢慢进入状态|
|🍬心动试探|轻轻反问、顺手接梗，那半句话可能是在约下次|
|♟️暧昧过招|聊得来，想法却未必一样；需要试探，也需要说清楚|
|🔥地狱修罗场|更多含糊回应、期待落差和取舍，看看自己愿意投入到哪里|

模型模式会结合适用角色和前情调整表达与张力；离线模式提供对应的氛围指引，回应仍来自预写分支。现场可以降低强度，重演也不会偷偷升回高档。

难度与关系类型分别选择。长期关系可以有拉扯，轻松认识也可以很坦诚。明确拒绝、暂停和退出在每一档都有效。

## 🗺️24个活动，约在哪里由你选

|分类|活动|
|---|---|
|🍜吃喝|咖啡茶饮、餐厅约饭、火锅烤肉、夜市小吃|
|🎬文娱|电影院、美术馆展览、书店|
|🌿户外|公园散步、CityWalk、骑行、野餐短徒步|
|🛍️逛街|市集快闪|
|🏺手作|陶艺、烘焙、饰品绘画|
|🎲游戏|桌游、台球、保龄球、电玩城|
|🏸运动|羽毛球、攀岩|
|🌙夜间|清吧、热闹酒吧、Livehouse|

每个活动有6个核心节点和专属动作。陶艺可以选形状、救杯沿、请店员收好；烘焙需要分工、等待和分装；电影与演出期间少说长话，散场后再聊。

动作会改变物件、进度、位置、时间或模拟消费。保留歪杯子、换一家摊位、承认自己不会，都可以继续。

**想续第二站？先商量。**候选会检查人物兴趣、剩余时间、预算和虚构营业时段；单独确认后才出发，也能撤回。预约、售票和运动活动不会临时自动入场。活动价格、时长和营业时段均为虚构设定，不是现实商户信息。

## 🎭32位角色，各自有自己的生活

人物按兴趣参加不同活动，也有各自适用的体验模式。匹配会考虑对象条件、活动、相处偏好和兴趣；选定模式后，候选范围会进一步缩小。

|人物举例|相处时的样子|之后还有什么安排|
|---|---|---|
|林澈|有自己的选项，说话直接，也能一起安静待着|取修好的相机|
|陈诺|稍紧张，愿意尝试，也会承认自己不会|归还借来的工具|
|许棠|喜欢沿河走路、研究桌游规则，在意意见不同还能否自在相处|照看朋友寄养的猫|
|苏晴|喜欢轻合作游戏，希望输了也能正常聊天|回家处理预约维修|

角色可以主动提议、表达不同意见、没接住玩笑，再试着澄清。共同笑点来自本场真正发生的事，互动例子只教表达方式，不冒充你们的共同记忆。

男生视角匹配女性角色，女生视角匹配男性角色；其他视角按所选对象偏好匹配。所有角色均为原创虚构成年人，没有真人原型。

## 🪄从开场到散场，怎么玩

|环节|你做什么|现场如何回应|
|---|---|---|
|**①选个开局**|确认成年，选视角、强度和活动；也可盲约|按条件给出候选，预算或时间不足会说明原因|
|**②定本场期待**|选初见、二见、朋友、暧昧或稳定交往；表达轻松认识、认真了解或暂不决定|关系起点与期待分别记录，不自动代表双方达成一致|
|**③看见面便笺**|看看人物的兴趣、风格和安排，赴约或换一位|对方带着自己的想法进入现场|
|**④自由互动**|自己说话，或选眼前的动作；可以接梗、留白、提议和拒绝|模型接话，合法活动动作经验证后改变现场状态|
|**⑤决定怎么收场**|按约定离开、提前散场，或商量可行的第二站|时间、预算和双方已经说清的边界继续生效|
|**⑥回看与带走**|选一个在意的回合，重演或写下发现，也可以直接结束|原场与重演分别保存，按需生成回看和Dating卡|

时间、模拟预算、饮食、饮酒、活动经验和希望协商的排他方式可在细项中设置。不喝酒仍能去酒吧选择无酒精饮品。称呼、个人期待便笺无需填写，私人便笺不默认发送给模型。

### ⏸️卡住、想歇会儿，或想换个说法

- **我有点卡住：**查看眼前可行的行动方向。
- **暂停／回到现场：**从同一刻继续，真实等待不扣剧情时间。
- **取消请求：**停止等待中的模型回合；失败保留输入，可重试。
- **提前散场：**结束本场，再决定是否回看。
- **从这一幕重演：**散场后选择一个节点，试一次其他做法；每场可完成一次重演。
- **结束并清空这场：**删除本地服务中的原场与重演记录，回到封面。

模型模式目前整轮显示回应，未提供逐字流式。模型出错时会明确提示，不会悄悄切换成预写台词。普通聊天不会自动确认邀约或切换第二站。

## 🎟️散场之后，带走一点什么

|产物|里面有什么|
|---|---|
|**HTML约会回看**|现场动作、台词、结果、选中的一刻和实际完成的重演|
|**个人Dating卡**|一张4:5的SVG便笺，放一句你确认过的发现和可选观察点|

回看按“发生了什么→我当时在意什么→我想带走什么”展开。可以把候选发现改成自己的话，确认后再放进卡片；跳过自述也能结束，回看会保留现场与待观察的问题。

赴约期待和私人便笺分别勾选后才加入HTML，卡片下载前可预览。单次体验即可完整结束，不要求建立长期档案或持续打卡。

## 🔐数据与使用范围

- 面向18岁以上用户。人物、活动价格与行程均属虚构，不代表现实关系诊断。
- 离线体验不请求模型；模型模式会向你配置的服务发送本场设置与对话，密钥只由本地服务读取。
- 模型会话暂存在服务进程内存，空闲2小时后自动清理；主动清空或停止服务也会释放记录。下载文件由你保存。
- HTML可能包含现场原话，无法保证自动识别所有个人信息。卡片会过滤部分身份信息与照抄台词，分享前仍需核对。
- 模型可能误解语义。系统校验合法动作与部分严重事实矛盾，但不能保证每一句都自然或完全符合前情。

## 🛠️开发与验证

无需安装第三方依赖。在仓库根目录运行：

```powershell
node --test tests
```

自动测试覆盖活动目录、角色匹配、可执行路径、活动状态、语义动作、第二站、暂停取消、重试、降档重演及导出。模型接口测试使用本地模拟服务。

浏览器已验证目录、设置、开局、跨站时钟、降档和暂停等流程。真实外部模型的语气、延迟、费用与手机浏览器表现仍需分别实测，自动测试通过不等于真人感已验证。
